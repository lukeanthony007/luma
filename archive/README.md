# Previous Luma implementation

[obsidian-plugin/](obsidian-plugin/) preserves every tracked file from Luma commit [`dbfd14bcd1fb9b0deed36c94be382965bae56d78`](https://github.com/lukeanthony007/luma/commit/dbfd14bcd1fb9b0deed36c94be382965bae56d78), the `main` tip used to begin the PKM redesign.

The files were relocated without content changes, including the original source, generated `main.js`, build configuration, lockfile, README and license. The original Git history remains available. This is a snapshot of tracked repository content, not a backup of installations, personal vaults or untracked files from other machines.

The archived README describes the previous project's claims and plans; it is not documentation for the new Luma foundation. Its license label differs from the accompanying [LICENSE](obsidian-plugin/LICENSE); the license file is preserved as supplied. Runtime behavior and the archived dependency stack have not been revalidated as part of the archival move.

Treat this directory as historical reference. Future Luma development starts at the [repository root](../README.md). Reuse specific code deliberately; the archive's manifests, build scripts and instructions do not configure the new project.
